Project 03

IoT-Based Smart Shoe Using Piezoelectric Technology

IoT,Embedded,ESP32

A smart wearable shoe integrated with a piezoelectric module and ESP32 that enables real-time communication in critical scenarios such as trekking, rescue, or defense. The project focuses on harvesting energy through a piezoelectric shoe sole, converting mechanical pressure from walking into usable electrical energy. Push-buttons embedded in the shoe allow the user to trigger predefined actions, such as sending location coordinates or emergency SOS messages, via MQTT to a base camp. The solution provides a low-cost, portable, and reliable emergency communication tool that enhances safety for soldiers, trekkers, and individuals in remote or high-risk environments.
